# GC — GameCube (2001)

- **Estado:** Solo con Linux — fuera de la hoja de ruta
- **Core en la PS4:** ninguno. Dolphin necesita OpenGL 3.3 / GLES 3.0 / Vulkan y el port de RetroArch para PS4 solo llega a OpenGL ES 2
- **Extensiones:** `.iso` `.gcm` `.rvz` (Dolphin)
- **BIOS:** no necesita

**Notas:** Arrancando Linux en esta PS4 (disponible en 12.52) Dolphin funciona: hay informes de *Pikmin* a 50 fps en PS4 Pro con OpenGL. Qué implica y por qué no está planificado, en [`../../emuladores-ps4.md`](../../emuladores-ps4.md#solo-con-linux--gamecube-wii-ps3-y-ps-vita). Sin probar en esta consola.
