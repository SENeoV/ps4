# SEGACD — Sega CD / Mega CD (1991)

- **Estado:** Tanda 3 — necesita BIOS
- **Cores instalados en la PS4:** `genesis_plus_gx` (recomendado), `picodrive`
- **Extensiones:** `.chd` `.cue`
- **BIOS** (en `/data/retroarch/system/`, salvo que se indique otra cosa):
  - `bios_CD_U.bin` — USA — ✅ ya subida
  - `bios_CD_E.bin` — Europa — ✅ ya subida
  - `bios_CD_J.bin` — Japón — ✅ ya subida, pero es la revisión `jp_mcd1_9112` (SHA-1 `e4193c…`), no la que libretro espera (`4846f4…`). Debería arrancar igual; si un juego japonés falla, cambiarla
