# ARCADE/FBNEO — Arcade — FB Alpha 2012

- **Estado:** Tanda 2 — arcade
- **Cores instalados en la PS4:** `fbalpha2012` (recomendado), `fbalpha2012_cps1`, `fbalpha2012_cps2`, `fbalpha2012_cps3`
- **Extensiones:** `.zip`
- **BIOS:** no necesita
- **Romset:** FB Alpha 2012 `v0.2.97.29` para `fbalpha2012` y `fbalpha2012_cps3`; **`v0.2.97.28`** para `fbalpha2012_cps1` y `fbalpha2012_cps2` (según sus `.info`). Entre esas dos revisiones casi todo coincide, pero si un juego de CPS1/CPS2 no arranca con el set `.29`, probar el `.28`

**Notas:** La carpeta se llama FBNEO por la guía original, pero en la PS4 el core es **FB Alpha 2012**, no FinalBurn Neo: los romsets de FBNeo actual no valen. CPS1, CPS2 y CPS3 tienen cores dedicados.

_Cores, extensiones y BIOS verificados contra los `.info` de los cores instalados (2026-09-13). El rendimiento sale de informes de la comunidad y aún no se ha probado en esta consola._
