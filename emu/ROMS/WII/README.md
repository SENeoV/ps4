# WII — Wii (2006)

- **Estado:** Solo con Linux — fuera de la hoja de ruta
- **Core en la PS4:** ninguno. Mismo motivo que GameCube: Dolphin exige OpenGL 3.3 / Vulkan, que el port de RetroArch para PS4 no ofrece
- **Extensiones:** `.iso` `.wbfs` `.rvz` (Dolphin)
- **BIOS:** no necesita

**Notas:** Bajo Linux en esta PS4 Dolphin funciona (ver GameCube), pero la Wii añade el problema del mando: sin Wiimote hay que mapear el puntero al DualShock. Sin probar en esta consola. Detalle en [`../../emuladores-ps4.md`](../../emuladores-ps4.md#solo-con-linux--gamecube-wii-ps3-y-ps-vita).
