# Los tres grandes que conviene separar

## PS1

Para PS1, si buscas **calidad de imagen**, yo utilizaría:

**Beetle PSX HW**

antes que PCSX-ReARMed.

También existe SwanStation. La diferencia fundamental es que Beetle PSX HW permite una renderización mucho más avanzada que el core antiguo PCSX-ReARMed. La documentación de RetroArch distingue precisamente entre PCSX-ReARMed, Beetle PSX y Beetle PSX HW. ([GitHub][4])

Para una colección moderna utilizaría:

```text
PS1/
├── Game 1.chd
├── Game 2.chd
└── Game 3.chd
```

El formato **CHD** es particularmente interesante porque reduce el número de archivos y el espacio utilizado.

# PSP

Aquí tienes una de las mejores situaciones:

La PS4 Pro puede mover una gran cantidad del catálogo de PSP con muy buenos resultados.

También puedes encontrar PPSSPP como core de RetroArch, aunque para PSP prefiero **PPSSPP standalone** si tienes una versión PS4 funcional disponible.

# Dreamcast

Para Dreamcast:

### Flycast / Reicast

```text
Dreamcast/
├── Sonic Adventure/
│   └── game.gdi
├── Crazy Taxi/
│   └── game.cdi
```

Aquí hay una particularidad: el soporte standalone de Flycast para PS4 ha tenido históricamente limitaciones, y existe documentación de la propia comunidad de desarrollo señalando que el core Flycast de RetroArch para PS4 estaba desactualizado en determinado momento. ([GitHub][5])

Por eso **comprobaría la build concreta antes de decidir qué versión instalar**.

# Arcade: aquí hay una trampa importante

No mezcles:

```text
MAME
FBNeo
```

como si fueran el mismo sistema.

Una ROM de MAME de una determinada versión puede **no funcionar con otra versión de MAME**.

Lo mismo ocurre con FBNeo.

Por ejemplo:

```text
Arcade/
├── FBNeo/
└── MAME/
```

Y cada colección debería corresponder a la versión del emulador.

Esto es especialmente importante si en algún momento quieres montar una colección grande.
