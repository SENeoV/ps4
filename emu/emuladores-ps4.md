# Emuladores por plataforma — PS4 Pro + GoldHEN 12.52

Guía de referencia rápida para montar la retro-colección. ROMs y BIOS: originales, obtenidas por el usuario.

### Leyenda de compatibilidad

- 🟢 Excelente — prácticamente sin problemas
- 🟢/🟡 Muy buena — algunos juegos pueden necesitar ajustes
- 🟡 Buena/variable — depende bastante del juego/core
- 🟠 Experimental — funciona, pero no para montar la colección alrededor
- 🔴 No recomendable — existe algún proyecto, pero no es práctico

## Priorización para instalar

### Nivel 1 — instalar sí o sí (potencia de sobra)

```
NES, SNES, Game Boy, Game Boy Color, Game Boy Advance,
Master System, Game Gear, Mega Drive, PC Engine, Neo Geo,
Arcade/FBNeo, PS1, PSP, Dreamcast, N64, MSX, DOS
```

### Nivel 2 — excelentes pero requieren configuración

```
Sega CD, 32X, PC Engine CD, Neo Geo CD, 3DO,
Commodore 64, Amiga, ZX Spectrum, Nintendo DS, Saturn
```

Saturn: la emulación existe en PS4 (Yabause como port nativo), pero la compatibilidad no es comparable a PS1 o SNES.

### Nivel 3 — experimental

```
PS2
```

No asumir que "PS4 Pro = PS2 perfecta". Mast1c0re usa el emulador PS2 nativo de la propia PS4 y permite cargar ISOs, pero con limitaciones de compatibilidad.

## Los tres grandes, en detalle

### PS1

Preferir **Beetle PSX HW** sobre PCSX-ReARMed (renderizado mucho más avanzado). También existe SwanStation como alternativa.

Formato recomendado: **CHD** (reduce archivos y espacio).

```
PS1/
├── Game 1.chd
├── Game 2.chd
└── Game 3.chd
```

### PSP

**PPSSPP** — muy buen rendimiento en PS4 Pro. Preferir la versión standalone sobre el core de RetroArch si hay un build PS4 funcional.

```
PSP/
├── Game 1.iso
├── Game 2.cso
└── Game 3.iso
```

### Dreamcast

**Flycast / Reicast**. El soporte standalone de Flycast en PS4 ha tenido limitaciones históricas y el core de RetroArch ha estado desactualizado en algún momento — comprobar la build concreta antes de instalar.

```
Dreamcast/
├── Sonic Adventure/game.gdi
├── Crazy Taxi/game.cdi
└── ...
```

## Arcade: no mezclar

MAME y FBNeo no son intercambiables, y una ROM de una versión de MAME puede no funcionar con otra versión del mismo emulador. Mismo caso con FBNeo.

```
Arcade/
├── FBNeo/
└── MAME/
```

Cada colección de ROMs debe corresponder a la versión exacta del emulador usado.

## Dónde instalar

**Homebrew Store** en la PS4 con GoldHEN — permite descargar/instalar RetroArch, SNES Station y otros directamente desde la consola.

Referencias:
- [PS4 Emulators & Homebrew — ConsoleMods](https://consolemods.org/wiki/PS4%3AEmulators_and_Homebrew_Games)
- [PS4 Homebrew Store — ConsoleMods](https://consolemods.org/wiki/PS4%3AHomebrew_Store)
- [RetroArch — GitHub oficial](https://github.com/libretro/RetroArch) (incluye target `orbis` para PS4)

**Nota:** no actualizar el firmware 12.52 solo para conseguir una versión más nueva de un emulador — la versión de firmware es una variable crítica en una consola con GoldHEN.
