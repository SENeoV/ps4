# EXTRAS — apartado, no se sube a la PS4

Archivos que venían con las ROMs pero no son juegos jugables. Están **movidos, no borrados**.

| Carpeta | Contenido |
|---|---|
| `EXTRAS/GB/` | BIOS de dispositivos: trucos (Game Genie, Game Shark, Action Replay), copiadores (Smart Card, Backup Station, Challenger) y utilidades (Work Master) |
| `EXTRAS/GBA/` | `.sgm`: savestate de VisualBoyAdvance. RetroArch no lo lee |

Cada movimiento de la limpieza está registrado en [`../../cleanup-2026-09-12.tsv`](../../cleanup-2026-09-12.tsv) (origen, destino y motivo), así que se puede deshacer.

No se suben al repo (binarios, ignorados por git).
